## Proposito

Partiendo de una plantilla estándar donde se definen las features de una pieza, se genera el código de PLC para el estándar SICAR@GST de configuración de tecnologías
de trazabilidad, así como la base del documento excel donde se muestran todas esas features para la plataforma I4 de GEESTAMP.

## Instrucciones

- Seleccionar la plantilla completada con las características de la pieza.
- Elegir destino para el excel generado (si se deja por defecto se crea un archivo "_PLC" con el nombre del original.
- Configurar cantidad de referencias definidas en la plantilla.
- Pulsar botón de generación.
